# Section 10: Adding Forms To Websites
## Important Form HTML Elements
- **<input type="..."">** `The "type" attribute controls which type of input will be shown (e.g. single line text input, number, email address input, ...)`
- **<textarea>** `A multi-line text input field` 
- **<select>** `A dropdown multiple-choice or multi-select input` 
- **<button>** `A button to reset or submit the form`
